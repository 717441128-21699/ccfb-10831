# 农批市场价格指数采集平台（全本地仿真）

本项目**只针对本地仿真网站**采集，不访问任何真实批发市场官网。

## 架构

| 模块 | 端口 | 反爬花招 | 采集对策 |
|---|---|---|---|
| `mock_sites/m1_font/` 鑫丰农贸 | 8011 | 每日更换的自定义字体，源码里价格是 PUA 乱码 | 每日自动重解字体映射（探针渲染 + 字形归一化匹配） |
| `mock_sites/m2_canvas/` 城南批发市场 | 8012 | 价格画在 Canvas 上；另有一个偶尔对不上的 JSON 渠道 | 连通域切分 + 渲染模板 OCR，并与第二渠道交叉印证 |
| `mock_sites/m3_sign/` 临港果批 | 8013 | 接口参数签名由页面 JS 现算，算法按日期轮换、夹带诱饵函数 | 从页面脚本中发现签名函数并在浏览器内执行，不写死算法 |
| `mock_sites/m4_pdf/` 西山产地市场 | 8014 | 只发跨页周报 PDF | pdfplumber 拆跨页表、续行合并，按价格类型分列 |

## 目录

- `common/`：配置、商品目录、仿真真值生成、休市日历、字体构造工具
- `collector/`：Playwright 采集器、字体解码器、Canvas OCR、签名发现器、PDF 解析、调度/补采、异常复核
- `admin/`：FastAPI + Jinja2 后台（市场管理 / 采集日历 / 原始快照 / 价格库 / 异常价格）
- `harness/`：连跑 30 天并与仿真真值逐条比对
- `runtime/`：运行期数据（SQLite、快照、字体、PDF、报告），不入库 git

## 快速开始

```powershell
.\.venv\Scripts\python.exe -m scripts.setup_all        # 建库 + 起 4 个仿真站 + 跑 30 天采集 + 真值比对
.\.venv\Scripts\python.exe -m admin.main               # 后台 http://127.0.0.1:8000
```

或分步执行，见 `scripts/` 下各脚本。

## 关键业务规则

1. 字体映射每日更换，采集端每次运行自动重解，不沿用历史映射
2. Canvas 数字本地 OCR，并与独立渠道交叉印证，不一致进异常
3. 签名算法通过在页面内试跑候选函数获得，代码库不含任何写死的签名逻辑
4. PDF 跨页表格按表头/续行规则还原为明细行
5. 批发价 / 产地价 / 到岸价分字段存储（DB CHECK 约束 + 写入层路由），不会串
6. 休市日不算缺数；补采只补「应开市但无价格」的日期
7. 每条价格都带 `snapshot_id`，可回溯原始截图与原始报文
8. 日涨跌幅超过 3 倍（或低于 1/3）先置为「扣留」，人工复核后才入库价格库
